# /make_api_doc — API 문서 자동 생성

## 입력 (인자)

| 형식 | 동작 |
|---|---|
| `/make_api_doc` | `backend/app/routers/*.py` 전체를 분석합니다. (기본값) |
| `/make_api_doc courses` | `courses.py` 라우터 하나만 분석하고, 기존 문서의 나머지 섹션은 유지합니다. |
| `/make_api_doc <파일 경로>` | 지정한 라우터 파일 하나만 분석합니다. |

인자가 없으면 전체를 분석합니다. 인자가 라우터 이름이나 경로와 맞지 않으면 작업을 멈추고 사용 가능한 이름 목록을 보여 줍니다.

## 출력

- **저장 위치:** `myAIEdu/docs/API.md` (단일 파일)
- **갱신 방식:** 파일 전체를 덮어씁니다. 부분 갱신일 때는 해당 라우터 섹션만 바꾸고 나머지는 그대로 둡니다.
- **언어:** 한국어. 경로, 필드명, 코드 값은 원문 그대로 씁니다.

## 분석 절차

아래 순서를 지킵니다. 추측으로 채우지 않고, 코드에서 확인한 내용만 씁니다.

### 1단계: 대상 확인

1. `backend/app/routers/` 폴더를 확인합니다. `__init__.py`는 제외합니다.
2. `backend/app/main.py`에서 `include_router`로 등록된 라우터 목록을 확인합니다.
3. 등록되지 않은 라우터 파일이 있으면 문서에 넣지 않고, 결과 보고에 "미등록 라우터: 파일명"으로 적습니다.

### 2단계: 라우터 파일 읽기

각 라우터 파일에서 아래 항목을 찾습니다.

- `APIRouter(prefix=..., tags=[...])`: 기본 경로와 태그
- `@router.get|post|patch|put|delete(...)` 데코레이터: 메서드, 경로, `response_model`, `status_code`, `dependencies`
- 함수 시그니처: 경로 매개변수(`{course_id}` → `int`), 본문 매개변수(`data: EnrollmentCreate` 같은 스키마)
- `dependencies=[Depends(require_admin)]`이 있으면 **관리자 전용**으로 표시합니다.

**전체 경로 계산:** `prefix + 데코레이터 경로`입니다. 데코레이터 경로가 `""`이면 prefix 자체가 경로입니다. 예: `prefix="/courses"`, `@router.get("")` → `GET /courses`.

### 3단계: 스키마 읽기

`response_model`과 본문 타입에 쓰인 클래스를 `backend/app/schemas/`에서 찾아 아래를 기록합니다.

- 필드 이름, 타입, 필수 여부 (`Optional[...]`이거나 기본값이 있으면 선택)
- `Field(min_length, max_length, ge, le, default)` 제약
- `Literal[...]`로 정한 허용 값 목록
- `@field_validator`에서 던지는 `ValueError` 메시지 (사용자에게 보이는 검증 규칙)

**주의:** 스키마 클래스가 다른 클래스를 상속하면 부모의 필드도 포함합니다. 예: `CourseDetailOut(CourseOut)`은 `CourseOut` 필드를 모두 가집니다.

### 4단계: 오류 응답 찾기

1. 라우터가 호출하는 서비스 함수를 `backend/app/services/`에서 찾습니다.
2. 서비스 함수 안의 `raise NotFoundError(...)`, `raise ConflictError(...)`, `raise AuthError(...)`, `raise ServiceUnavailableError(...)`를 모두 찾습니다.
3. 각 예외의 상태 코드는 `backend/app/core/errors.py`에서 확인합니다.
   - `AppError` 기본: 400, `NotFoundError`: 404, `ConflictError`: 409, `AuthError`: 401, `ServiceUnavailableError`: 503
4. 관리자 엔드포인트는 `require_admin`이 401 또는 503을 낼 수 있습니다.
5. FastAPI 자체 검증 실패는 `main.py`의 `validation_error_handler`가 422로 응답합니다. 모든 엔드포인트 공통 항목으로 한 번만 적습니다.
6. 오류 본문 형식은 공통입니다: `{"detail": "메시지"}`

### 5단계: 문서 조립

아래 템플릿으로 엔드포인트마다 섹션을 만듭니다. 파일 맨 위에는 공통 섹션을 둡니다.

### 6단계: 검증 (작성 후 반드시 수행)

문서를 저장하기 전에 아래를 모두 확인합니다.

- [ ] 문서의 엔드포인트 수가 2단계에서 찾은 데코레이터 수와 같습니다.
- [ ] 모든 경로와 메서드가 실제 데코레이터와 일치합니다. 오타가 없는지 다시 대조합니다.
- [ ] 필드 이름과 타입이 스키마 파일과 일치합니다.
- [ ] 코드에 없는 설명을 만들지 않았습니다. 설명이 필요한데 코드에 근거가 없으면 `[확인 필요]`로 표시합니다.
- [ ] 관리자 엔드포인트에 `관리자 전용` 표시와 `X-Admin-Key` 헤더 설명이 있습니다.
- [ ] 샘플 요청과 응답 값은 실제 스키마 제약을 지킵니다. 예: 전화번호는 숫자만, `consent`는 `true`.

검증에 실패하면 문서를 저장하지 않고, 어떤 항목이 어긋났는지 보고합니다.

## 마크다운 템플릿

### 파일 맨 위 (공통)

```markdown
# 4050 AI 교육 API 문서

- 버전: {FastAPI 앱의 version 값}
- 기본 주소: `http://127.0.0.1:8000`
- 대화형 문서: `http://127.0.0.1:8000/docs`
- 생성 시각: {YYYY-MM-DD}
- 생성 근거: `backend/app/routers/`, `backend/app/schemas/`, `backend/app/services/`

## 공통 규칙

- **관리자 인증:** 관리자 전용 엔드포인트는 헤더 `X-Admin-Key`가 필요합니다. 값이 없거나 틀리면 `401`을 반환합니다.
- **오류 형식:** 모든 오류 본문은 `{"detail": "메시지"}`입니다. 메시지는 한국어입니다.
- **검증 실패:** 입력값이 규칙에 맞지 않으면 `422`를 반환하고, 첫 번째 오류 메시지를 `detail`에 담습니다.

## 목차

- [{태그명}](#{앵커})
```

### 라우터별 섹션

```markdown
## {태그명} ({라우터 파일명})

{라우터의 한 줄 설명. 코드에 근거가 없으면 생략합니다.}

### {메서드} {전체 경로}

{엔드포인트 한 줄 설명. 함수 이름과 독스트링에서 근거를 찾습니다.}

- **인증:** 공개 / **관리자 전용** (`X-Admin-Key` 헤더 필요)
- **성공 응답:** `{status_code}` {상태 문구}

**경로 매개변수**

| 이름 | 타입 | 설명 |
|---|---|---|
| {name} | {int 등} | {설명 또는 [확인 필요]} |

**요청 본문** (`{스키마 클래스명}`)

| 필드 | 타입 | 필수 | 제약 | 설명 |
|---|---|---|---|---|
| {field} | {type} | 예 / 아니오 | {min_length, 허용 값, 검증 메시지 등} | {설명 또는 [확인 필요]} |

**응답 본문** (`{스키마 클래스명}`)

| 필드 | 타입 | 설명 |
|---|---|---|
| {field} | {type} | {설명 또는 [확인 필요]} |

**요청 예시**

```http
{메서드} {전체 경로}
Content-Type: application/json
{관리자 전용이면 X-Admin-Key 헤더 줄}

{JSON 본문 (요청 본문이 없으면 이 블록을 생략)}
```

**응답 예시**

```json
{스키마 제약을 지키는 실제 형태의 JSON}
```

**오류 응답**

| 상태 코드 | 조건 | 본문 예시 |
|---|---|---|
| {code} | {서비스가 이 오류를 내는 조건} | `{"detail": "{실제 raise 메시지}"}` |
```

### 목록 응답 표기

`response_model=list[X]`이면 응답 본문 제목을 `**응답 본문** (`list[X]`)`로 씁니다.

## 예시 (courses 라우터 일부)

아래는 실제 코드 기준으로 만든 예시입니다.

```markdown
## courses (courses.py)

### GET /courses

모집 중인 과정 목록을 반환합니다.

- **인증:** 공개
- **성공 응답:** `200` OK

**응답 본문** (`list[CourseOut]`)

| 필드 | 타입 | 설명 |
|---|---|---|
| id | int | 과정 ID |
| title | str | 과정명 |
| description | str \| null | 과정 소개 |
| price | int \| null | 수강료(원). 확정 전이면 null [확인 필요] |
| capacity | int | 정원 |
| is_open | bool | 모집 여부 |
```

## 작성 원칙

- 한 엔드포인트에 한 섹션입니다. 여러 엔드포인트를 묶지 않습니다.
- 표의 설명은 짧게 씁니다. 필드 설명을 코드에서 찾을 수 없으면 추측하지 말고 `[확인 필요]`로 둡니다.
- 한국어 오류 메시지는 코드에 있는 문자열을 그대로 옮깁니다. 바꾸거나 번역하지 않습니다.
- 개인정보 예시 값은 가짜 값만 씁니다. 실제 번호나 이메일을 넣지 않습니다. 예: `010-0000-0000`.
- 문서를 만든 뒤 프론트엔드 `app.js`의 API 호출 경로가 문서와 맞는지 확인하고, 다르면 결과 보고에 적습니다.

## 경로 변경 시

백엔드가 `src/back/`으로 마이그레이션되면 이 문서의 `backend/` 경로를 모두 `src/back/`으로 바꿉니다. 경로 변경은 `.claude/rules/architecture.md` 0절 갱신과 함께 진행합니다.
