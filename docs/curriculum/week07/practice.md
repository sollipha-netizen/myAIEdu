# 7주차 실습 가이드: 퍼스널 브랜딩 완성형

> 목표: 60분 안에 한 줄 소개, 3줄 프로필, SNS 소개글, 한 장짜리 프로필 페이지를 완성합니다.
> 주의: 실제 회사 내부 정보, 고객 이름, 전화번호는 AI에 넣지 않습니다.

## 1단계: 경력 재료 정리 (15분)

아래 표를 종이나 메모장에 채웁니다. 문장을 예쁘게 쓰지 말고 **사실만 짧게** 적습니다.

| 항목 | 내 답 |
|---|---|
| 해 온 일 (분야와 연차) | 예: 제조 현장 품질관리 22년 |
| 숫자로 말할 수 있는 성과 2개 | 예: 불량률 3.2% → 0.8%, 인증 심사 5회 통과 |
| 남들이 나에게 자주 묻는 것 | 예: 불량 원인 찾는 법 |
| 돕고 싶은 사람 | 예: 품질 인증을 처음 준비하는 소규모 공장 |
| 원하는 말투 | 예: 믿음직하고 차분하게 |

**막힐 때 AI에게 묻기**

```
저는 [분야]에서 [연차] 일했습니다. 제 강점을 찾도록 저에게 질문 5개를 해 주세요.
한 번에 하나씩 묻고, 제 답을 듣고 다음 질문을 해 주세요.
```

## 2단계: 한 줄 소개 만들기 (15분)

### 방법 A: 예시 코드로 질문 만들기 (권장)

1. `examples/brand_prompts.py`를 엽니다.
2. 파일 아래쪽 `SAMPLE_PROFILE`의 값을 1단계에서 적은 내 내용으로 바꿉니다.
3. 터미널에서 실행합니다.

   ```bash
   python brand_prompts.py
   ```

4. 화면에 나온 `[1] 한 줄 소개` 질문을 복사해 AI 대화창에 붙여 넣습니다.

### 방법 B: 직접 질문 쓰기

```
당신은 40·50대 경력 전환을 돕는 코치입니다.
아래 사실만 사용해서 한 줄 소개를 3개 만들어 주세요.
- 경력: (1단계 내용)
- 성과: (1단계 내용)
- 강점: (1단계 내용)
- 돕고 싶은 사람: (1단계 내용)
조건: 각 40자 이내, 말투는 (원하는 말투), 제가 적지 않은 성과나 숫자는 넣지 마세요.
```

### 고르고 고치기

- 3개 중 1개를 고르고, 소리 내어 읽어 어색한 단어를 내 말로 바꿉니다.
- 강의록 4절의 **검수 체크리스트**로 과장 표현을 지웁니다.

## 3단계: 3줄 프로필과 SNS 소개글 (15분)

`brand_prompts.py` 실행 결과의 `[2] 3줄 프로필`, `[3] SNS 소개글` 질문을 차례로 AI에 붙여 넣습니다.

| 결과물 | 쓰임 | 분량 |
|---|---|---|
| 3줄 프로필 | 강의 소개, 제안서, 명함 뒷면 | 3줄 |
| SNS 소개글 | 블로그, 링크드인, 카카오톡 프로필 | 150자 이내 |

**한 번 더 다듬는 질문**

```
방금 쓴 소개글을 50대 동료가 읽는다고 생각하고, 어려운 외래어를 쉬운 우리말로 바꿔 주세요.
```

## 4단계: 한 장짜리 프로필 페이지 (15분)

1. `examples/brand_profile.html`을 더블클릭해 브라우저로 엽니다.
2. 이름(또는 활동명), 한 줄 소개, 3줄 프로필, 대표 경험 3개를 입력합니다.
3. **미리보기 만들기** 버튼을 누르면 아래에 프로필 카드가 나타납니다.
4. 카드를 화면 캡처해 저장합니다. 입력 내용은 이 브라우저에만 남고 어디에도 전송되지 않습니다.

## 완료 확인

- [ ] 3줄 프로필
- [ ] SNS 소개글 (150자 이내)
- [ ] 프로필 카드 캡처 이미지

## 자주 묻는 질문

**Q. AI가 자꾸 거창한 표현을 씁니다.**
A. 질문 끝에 "광고 문구처럼 쓰지 말고, 동료에게 말하듯 담백하게 써 주세요."를 덧붙입니다.

**Q. 내세울 성과가 없는 것 같습니다.**
A. "오래 한 일", "실수 없이 반복한 일"도 성과입니다. 1단계의 "막힐 때 AI에게 묻기" 질문을 써 보세요.

**Q. 파이썬 실행이 안 됩니다.**
A. 방법 B(직접 질문 쓰기)로 진행해도 결과는 같습니다. 실행 문제는 쉬는 시간에 강사와 함께 확인합니다.
