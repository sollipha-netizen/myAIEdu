# 8주차 실습 가이드: 나의 경험, AI를 만나 비즈니스가 되다

> 목표: 60분 안에 서비스 아이디어 1개, 첫 달 수익 계산, 서비스 소개 페이지 초안, 첫 고객 검증 계획을 완성합니다.
> 주의: 재직 중인 회사의 내부 자료와 고객 정보는 AI에 넣지 않습니다.

## 1단계: 경험 자산 목록 (10분)

7주차 한 줄 소개를 맨 위에 적고, 아래 질문에 짧게 답합니다. 5개 이상 적습니다.

| 질문 | 내 답 |
|---|---|
| 처음 3년 동안 가장 많이 한 실수 | |
| 지금은 10분, 신입은 하루 걸리는 일 | |
| 지인이 자주 묻는 것 | |
| 나만 가진 요령이나 점검 순서 | |
| 오래 해서 지겹지만 남들은 어려워하는 일 | |

## 2단계: 서비스 아이디어 만들기 (15분)

1. `examples/business_canvas.py`를 엽니다.
2. `SAMPLE_IDEA`의 값을 내 내용으로 바꿉니다.
   - `one_liner`: 7주차 한 줄 소개
   - `assets`: 1단계에서 적은 경험 자산
   - `customer`: 돕고 싶은 사람
   - `problem`: 그 사람이 겪는 문제
3. 실행합니다.

   ```bash
   python business_canvas.py
   ```

4. `[1] 아이디어 발산` 질문을 AI에 붙여 넣습니다.
5. 받은 아이디어 3개를 아래 기준으로 평가해 1개를 고릅니다.

| 기준 | 아이디어 1 | 아이디어 2 | 아이디어 3 |
|---|---|---|---|
| 퇴근 후 시간으로 할 수 있다 (O/X) | | | |
| 첫 고객이 떠오른다 (O/X) | | | |
| 준비에 2주 이상 걸리지 않는다 (O/X) | | | |

## 3단계: 첫 달 수익 계산 (10분)

`business_canvas.py`의 `SAMPLE_PLAN` 값을 바꾸고 다시 실행하면 첫 달 예상 수익이 나옵니다.

| 항목 | 뜻 |
|---|---|
| `price` | 1회 가격 (원) |
| `customers_per_month` | 한 달 예상 고객 수 |
| `cost_per_customer` | 고객 1명당 드는 비용 (장소, 자료, 결제 수수료 등) |
| `fixed_cost` | 고객 수와 관계없이 드는 월 비용 (홍보, 도구 구독 등) |

- 결과의 **손익분기 고객 수**는 "몇 명을 받아야 손해가 나지 않는가"입니다.
- 가격은 AI 추천을 그대로 쓰지 말고, 비슷한 서비스 2곳의 가격을 직접 찾아 비교합니다.
- 예시 숫자는 계산 방법을 보여 주기 위한 가상의 값입니다.

## 4단계: 서비스 소개 페이지 초안 (20분)

1. 실행 결과의 `[3] 소개 페이지 문구` 질문을 AI에 붙여 넣습니다.
2. `examples/landing_page.html`을 더블클릭해 브라우저로 엽니다.
3. AI가 준 문구를 고쳐 서비스 이름, 대상, 해결하는 문제, 제공 내용 3가지, 가격, 신청 방법을 입력합니다.
4. **소개 페이지 만들기**를 누르고 결과를 캡처합니다.

**문구 검수**

- [ ] "100% 합격", "업계 최고"처럼 보장하거나 확인할 수 없는 표현이 없다.
- [ ] 내가 실제로 제공할 수 있는 내용만 적었다.
- [ ] 회사 이름이나 고객 이름이 들어가 있지 않다.
- [ ] 신청 방법에 개인 전화번호 대신 오픈채팅, 이메일 등 공개해도 되는 연락처를 적었다.

## 5단계: 첫 고객 검증 계획 (5분)

실행 결과의 `[2] 고객 검증 질문`을 AI에 붙여 넣어 인터뷰 질문을 받고, 아래 표를 채웁니다.

| 항목 | 내 계획 |
|---|---|
| 물어볼 사람 3명 (관계만, 예: 전 직장 후배) | |
| 언제까지 | |
| 꼭 물을 질문 3개 | |

## 자주 묻는 질문

**Q. 제 경험은 평범해서 돈이 될 것 같지 않습니다.**
A. 평범한 경험일수록 그 일을 처음 하는 사람이 많습니다. "누구에게" 팔지를 좁히면 가치가 생깁니다.

**Q. 가격을 얼마로 해야 할지 모르겠습니다.**
A. 처음에는 낮게 시작해 고객의 반응을 보고 올립니다. 무료로 하면 고객의 진짜 반응을 알기 어려우니 작은 금액이라도 받는 것을 권합니다.

**Q. 파이썬 실행이 안 됩니다.**
A. 수익은 `(가격 - 1명당 비용) × 고객 수 - 월 고정비`로 계산기에서 구해도 됩니다. 질문은 강의록 3절의 표를 보고 직접 써도 됩니다.
